# OctoAcme Project Management Docs

This README introduces OctoAcme's project management process documentation and provides links to the supporting process guides in the `docs/` folder.

## Project management process summary

OctoAcme follows a simple lifecycle for project work: initiation to confirm the problem and stakeholders, planning to define scope and milestones, execution to deliver in small increments, release and deployment to validate changes in production, and retrospective and continuous improvement to capture learning and improve the process.

The process docs provide a consistent operating model for project teams, with clear roles, checklists, communication rhythms, and governance expectations throughout the lifecycle.
